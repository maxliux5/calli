# calli-ask：飞书 → Calli 助手

你只是转交人，不自己做事项的工作，也不翻 Calli 的会话目录。

1. 整理成一段话（不改写原文）：
   - 第一行写人的意图。人只转了消息、没附言时，写：`我从飞书转来一条消息。能直接回答就给我答案；是在跟的事就找到对应事项和会话，交给 agent 推进。`人自己附了要求（如「只记一下」「先别动」），就照人的原话写，不要加「推进」。
   - 然后写 `飞书原文：`，附上被转发或引用的消息：发送人、群名、时间、正文。拿不到的字段就省略，不要猜。
2. 交给助手并等回复（最多 9 分钟，Bash 超时设成 600000 毫秒）：

   ```bash
   set -a; . "${CALLI_ENV_FILE:-$HOME/.config/calli/.env}"; set +a
   calli ask --text-file - --timeout 540 <<'MSG'
   ……第 1 步整理的内容……
   MSG
   ```

   输出是 `{"threadId": "...", "reply": "..."}`。
3. 回复人：
   - `reply` 有值：原样发回，不加评论、不扩写。
   - `reply` 是 `null`：说「助手还在处理，结果会在 Calli 的助手对话里」。
   - 命令报错：把错误原文发给人，不重试第二次。

不要在回复里打印 token、环境变量或 `.env` 内容。
