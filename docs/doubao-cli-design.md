# Doubao CLI 接入

## 原生接口

Calli 直接调用主机上已安装并登录的 Doubao CLI，不复制可执行文件、修改原生脚本或接管后台服务。Doubao CLI 2.37.2 提供 `model list --json` 和 `--output-format stream-json`；能力通过原生 `--help` 检测，不按版本号猜测。

旧版 CLI 没有这两个公开接口时，模型选择器隐藏，任务沿用 CLI 默认模型并返回最终文本。诊断显示 `cli_only`，不会尝试启动副本或把不可用的模型目录误报成账号故障。

旧副本桥已移除：原生后台服务会校验客户端可执行文件身份和脚本配置，复制后的运行包无法可靠复用现有服务。

## 安装与实例

先按 Doubao 当前发行说明安装并运行 `doubao login`。本机内部包为 `@bytedance-dev/doubao-cli`；公开发行包为 `@bytedance/doubao-cli`，不要与其他同名项目混淆。

新安装 Calli 默认从 PATH 寻找 `doubao`，`CALLI_DOUBAO_BIN` 可指定入口。已有安装从「配置 → Agents → 添加 agent」接入，不覆盖原有实例列表。实例的命令参数和环境传递给原生 CLI，不复制账号或凭据。

```json
{ "id": "doubao", "adapter": "doubao", "command": ["doubao"] }
```

可在实例命令中配置原生接受的 `--model`、`--effort`。网页选择只覆盖对应的下一轮参数，不修改全局设置。`-C` 放在业务参数之前，包装器参数仍保留在原位置。

## 模型目录

使用原生 `doubao model list --json`，不发探测提示词，不读取会话历史。严格解析 `result / success / model_list` 结果，返回账号实际可用模型、默认项及支持的推理强度；`none` 映射网页的 `off`。未知强度和无效结果明确报错。

每个实例缓存 60 秒并合并并发读取；显式刷新重新查询。读取失败保留此前成功目录，初次失败可以重试。查询输出上限 1 MB、超时 30 秒；只清理本次查询进程组，不停止原生共享服务。

切换模型或强度只影响下一轮，并续接同一个 `--resume` 会话。没有强度选项的模型清除旧覆盖；回到默认交给原生 CLI 决定。

## 流式回复

从实例「接入设置」启用「流式回复」，设置仍存为 Calli 实例环境 `CALLI_DOUBAO_STREAM: "1" / "0"`。旧设置无需迁移，下一轮生效，不打断当前任务。也可使用全局 `CALLI_DOUBAO_STREAM=1`，实例的显式关闭优先。

启用后使用原生 `--output-format stream-json`，不创建运行副本，也不占用额外运行包空间。当前 CLI 不支持时显示升级提示，保存仍成功，任务自动沿用最终文本回复。

正文解析原生 `stream_event` 增量、`assistant` 快照和最终 `result`，避免重复最终文本。工具解析原生 `tool_use` / `tool_result`，缺少输入或结果时保留未知状态，不猜测成功。取消只停止当前任务进程并保留会话 ID，后续任务可续接。

## 能力边界

默认权限为 `ask_risky`；无界面模式不能等待网页人工审批。完全访问模式沿用原生 bypass 参数。被原生拒绝的操作单独报告权限错误。

支持正文、多轮续接、取消、模型选择和流式工具事件。尚未接入图片、计划、额度、原生历史导入、分叉或会话删除；不把原生斜杠命令当普通提示词发送。

## 验证

回归覆盖原生命令参数、目录格式与失败重试、旧版默认模式、正文及工具事件、取消与续接、设置持久化和 HTTP 创建会话。网页检查覆盖桌面/手机和亮/暗模式；实际部署及真实 CLI 验证以本次执行结果为准。
