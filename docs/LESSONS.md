# 从已合入的改动里学到的

这个仓库的代码大多由 agent 写、改、合入。这里记的是：哪些改动后来又要返工，返工的那一类问题本该被哪条规则拦住。改代码前先读一遍。

每条的写法：**规则**，然后是为什么、证据（commit）和“出现天数”（在多少个不同的日子里看到同类返工）。同一条出现满 3 天，就把规则升级进 `AGENTS.md` 或测试，这里留一行“已升级”指过去，正文压成一句。

复盘方法：`git log --no-merges` 里 `fix`、`revert` 开头的提交，按“要是早知道哪条规则就不会返工”归类。复盘到哪个提交，写在第一行的 `reviewed-through`；下次从那里往后看。

证据：`dcf84b5`（11-03，安静计划行）→ `c50ffb6`（11-09，面板复用类名）→ 11-19 用户报「计划的样式太丑」，根因是串味不是设计。

### 10. 隐藏注入块不该出现在用户可见面

为什么：hub 给 agent 的 prompt 会追加 `<calli-*>` 协议块（进度、工具、引用、会议材料）。预览和标题的提取函数 `askedText` 原来只剥 `<calli-references>`，其他块跟着落进侧栏预览。信箱化之后成员信件的 `[进度]` 语义也依赖「协议文字只在机器通道」，可见面混进协议块会让人误读成员状态。

证据：线上库审计 `scripts/leak-audit.mjs`（11-20）：thread.preview 1207 条里 3 条带块（ebb74bf5、b87bdff9、71f88466）；displayText 10439 条 0 泄露、34 条设计内卡片。修复 `fc8fe24`（11-20）：`askedText` 剥所有行首锚定的 `<calli-*>` 块，行内代码提及保留。

出现天数：1。**规则**：`<calli-*>` 块只进 prompt（事件 `data.text`），不进 displayText、preview、标题。新增注入块后跑 `node scripts/leak-audit.mjs`（只读扫 hub.db，退出码 1 即有泄露，可挂 CI）；`packages/daemon/test/util.test.ts` 守住剥块规则。

### 11. 交接链的读取边界和回退目标，每个入口单独验证

为什么：交接链（handover/handback）的读取边界和回退目标藏在多个入口里——概况列表跳转、向后翻页、向前走、倒计时自动回退。新路径只测了自己那一段，别的入口还拿着旧的假设读链，三天里连修三次，其中一次把写给别人账号的简报递错了人。

证据：
- `4d5a108`（11-19）概况里点早期段：`readingPath` 向前走时丢了 successor 的 clip，页面停在交接后的旧会话尾部，真实的交接摘要反而没读到
- `483d978`（11-20）来回交接过的链向后翻页，落不到各段正确的位置
- `78708b2`（11-20）自动交接倒计时回退到“链上任意旧会话”，把为指定 successor 写的简报交给了没人选过的账号

出现天数：2。**规则**：改交接链的读取或回退，把每个入口（向前走、向后翻、概况跳转、自动倒计时）的落点和目标各写一个用例；回退目标只能是明确选定的那个会话，不允许“任意旧会话”兜底。

### 12. 协作协议块的语义教学不能互相覆盖

为什么：全局 `calli-progress` 块把「待验收」教成“做完请检查”，成员照它给纯确认信件也盖了待验收，每封都把 lead 叫醒。信箱语义（只有带新交付的交回才写待验收，纯确认写进行中并静默）写在协作块和成员块自己的说明里，但全局块的通用教学覆盖了它。

证据：`2ee2853`（11-20）协作块和团队成员块改为自带信箱语义，成员纯确认不再唤醒 lead（`packages/daemon/test/coordination.test.ts`）。

出现天数：1。**规则**：给 agent 的协议块改语义时，把语义写进受影响的每个块的说明里，不依赖全局块的通用教学；改完跑 `npm test -- coordination`。

### 13. 通用适配层的轮次生命周期不能只按单一 Agent 的特有信标做假设

为什么：ACP 适配层最初是按 Claude Code 的行为实现的（每轮必定以带费用的 `usage_update` 结束），并以此判定自主后台轮次（background turn）的终点。当接入 Antigravity（`agy`）、DeepSeek Harness（`dsh`）等不发费用报告的 ACP Agent 时，后台轮次启动后永远不会结算结束，变成幽灵轮次阻断后续操作。在自动交接（auto-handover）时发现被后台轮次冲突（409 conflict）阻断后，`d2bd3f4` 先在 `threads.ts` 加了 `stopBackgroundTurn` 强杀；一个半小时后 `6195dbf` 又返工到 `acp.ts` 补齐无费用 Agent 的静默超时（`backgroundIdleMs`）和连接关闭回收。

证据：
- `d2bd3f4`（11-23）自动交接被 agy 的后台轮次阻断，在 threads.ts 增加 stopBackgroundTurn 强杀
- `6195dbf`（11-23）返工根因：在 acp.ts 为无费用 Agent 补静默超时（backgroundIdleMs）并在连接断开时回收后台轮次

出现天数：1。**规则**：给通用协议（如 ACP）接入新 Agent 时，必须按该 Agent 自身的实际事件流验证完整的生命周期（开始 → 进行中 → 结束）；不能假设所有 Agent 都有特定信标（如费用报告），后台轮次必须具备静默超时和断连回收等兜底结束机制。

### 14. 动态层级与长路径面包屑必须有中段折叠和溢出截断

为什么：文件面板面包屑若只按一两层的短路径（如 `src/a.ts`）验证，真实环境遇到 agent 记忆或深层项目目录时，各级文字未截断溢出导致互相重叠，甚至横向压盖右侧操作区。

证据：`455c2c4`（11-23）深路径下文件面板面包屑相互重叠并压盖操作按钮；补 `collapseCrumbs` 折叠菜单与 CSS 截断，并在 `files-roots.spec.mjs` 中用真实深路径断言元素无重叠。

出现天数：1。**规则**：凡展示文件路径/层级面包屑的组件，必须设计中段折叠（如超过阈值收进 `...` 下拉菜单），文字节点加 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`；必须用真实深层路径（5 层以上）在 e2e 中做元素互不重叠的几何断言。

### 15. 侧面板展开导致主栏收窄时，浮层与边槽组件必须按主栏边界避让

为什么：文件、Git、终端等侧面板（Dock panel）展开会即时挤占主栏宽度。若菜单、Popover 按全屏视口计算浮动位置，会直接横向遮挡侧面板；常驻浮动卡片（如 overview dock）与新开面板或菜单重叠时也未让位；边槽过窄时标尺（TurnRuler）还会压盖正文。

证据：
- `085fc66`（11-24）侧面板打开后标尺挤压文字、主栏更多菜单与权限弹窗横向溢出盖住文件面板，概况卡片在菜单展开时未让位
- `f9cef93`（11-24）docked terminal 打开时常驻概况卡片未避让而悬浮在终端上方

出现天数：1。**规则**：侧边栏/抽屉展开时，主栏内浮层（Menu/Popover）的位置与最大宽度必须受限于主栏容器边界（如 `anchorBounds`），不能按 window 视口定位；边槽组件（如 TurnRuler）在可用间隙不足时主动隐藏；常驻浮动卡片必须在同区域面板或全高菜单展开时隐藏让位。

### 16. 移动端系统安全区与状态栏采样必须全局常驻真实 DOM，不能依赖伪元素或局部条件样式

为什么：iOS WebKit（尤其是 standalone PWA 与刘海/灵动岛机型）的系统状态栏颜色采样依赖视口顶部的真实 `position: fixed` DOM 节点，完全忽略 CSS 伪元素（如 `::after`）；采空时系统会强制下拉约 99pt 的毛玻璃羽化遮罩（blur pocket）遮盖顶栏。若试图通过给顶栏加 padding/offset 下移避让，会造成破坏视觉的额外留白；若通过局部视图类名（如 `:has(.composer-slot)`、`:not(.drawer-open)`）条件控制显示，在侧栏抽屉展开、键盘收起、冷启或前后台切换时，WebKit 合成器采样失效会把羽化遮罩永久卡死。

证据：
