## 方向

- [~] **P0** Agent 能力互借：统一 `calli tools` / `calli jobs` CLI、按需 Skill、反重力生图/搜索、Codex 搜索/网页读取，以及 Codex 通过动态工具操作 Calli 独立浏览器的 Computer use。操作系统桌面与反重力 IDE Browser Subagent 尚未接入。实现保留在独立 worktree，待用户验收；执行范围与验证记录见 [能力借用](borrowed-tools.md)。

以会话管理为基础，用一个简单的界面管理 agent、兼容的 agent 资源和外围工具。保持连接、对话、进展和审批这条日常路径轻巧；技能和 MCP 已有管理页面，其余资源与 Calli 扩展按第 6 节逐步推进。首版扩展宿主和「配置 → 扩展」已实现，支持内置扩展，以及本地目录或固定版本归档安装的外部工作数据源。

不做：代码编辑器、多用户账号、云端环境。终端例外：给人用的运维工具，见第 10 节。文件只看不改：只读的文件查看器，见第 11 节。

- [x] 修复：发送途中刷新页面，注释又回到输入框里（图片没了），看起来像只发出去了图片，再发一次就重复了。原因：存在本机的草稿要等发送请求回来之后再过 0.4 秒才清掉，而带图片的消息请求慢（上传，加上 daemon 先查模型能不能看图），这段时间里刷新，草稿就原样回来，图片只在内存里所以没了。现在：开始发送时给本机草稿标上「发送中」（发出去的全文，加当时线程里最后一条用户消息的轮次）；请求成功立刻删掉草稿；刷新后带着这个标记回来的草稿，等线程里出现一条新的、文字相同的用户消息就自动清掉，没出现（请求根本没到）就留着可以重发。发送超过 0.4 秒时发送按钮变成转圈并写「正在发送」

## 6. 扩展机制

用一个简单的界面，把 agent 和它周边的工具串起来。后续新增外围功能优先做扩展，按需启用；不装扩展仍能完成连接、会话、消息和审批。「配置 → 扩展」规划为统一入口，管理各家 agent 自己的扩展和独立开源工具；只向兼容的实例安装，保持机器与实例可见。Calli 扩展不进入 agent 循环，不改 prompt、不替人审批。通用配置写入权限仍待确认，现有技能/MCP 的特定入口不自动授权第三方扩展。设计见 [扩展设计](extensions-design.md)。

## 10. 终端

在网页里开一个真的终端（PTY），给自己在这台主机上跑命令：看 git 状态、跑测试、装依赖。不是把 IDE 搬进来：不持久化输出、不进事件日志、不碰 agent 的会话。

- [x] 决定：真终端要 PTY。daemon 引入 `node-pty`（常见平台有预编译）；主机上装不上就退回 `script -qfc $SHELL /dev/null` + `stty` 改窗口大小，零原生依赖。PTY 这层抽成小接口，两种实现同壳
- [x] 传输沿用 HTTP + SSE，不引 WebSocket：输出走 SSE，输入走 POST；xterm.js 在前端把击键按 ~16ms 合并成一批，keep-alive 下延迟够用
- [x] daemon `terminals.ts` + 接口：
  - `POST /api/terminals {cwd}` 建（起始目录必须在白名单里，之后的 cd 不管——daemon 本来就是远程 shell）
  - `GET /api/terminals` 列表；`POST …/:id/input {data}`（UTF-8）；`POST …/:id/size {cols,rows}`；`DELETE …/:id` 杀掉
  - `GET …/:id/stream` SSE：先补最近 ~256KB 环形缓冲（base64，应用可能输出非 UTF-8 字节），再接实时输出块，退出发 `exit(code)`；断线的 UTF-8 字符跨块拼接不丢
  - 生命周期：临时会话，daemon 重启即消失（不写 SQLite）；空闲 30 分钟回收；同时最多 3 个；daemon 退出时全杀；退出的会话保留 60 秒，重连还能看到结尾
  - shell 用 `$SHELL`（systemd 经登录 shell 启动，agent 的环境变量终端也能用），`CALLI_TERM_SHELL` 可覆盖
- [x] web `TerminalPanel.tsx`：`@xterm/xterm` + fit + web-links addon；全屏面板，头部是目录（短路径，悬停看全路径，点一下复制）、关闭（＋新建和多终端 Tab 留给 P1）；配色字号从 styles.css 变量读，16 色 ANSI 按亮暗各配一套，主题切换时换 theme；断线重连先重放缓冲再接实时（xterm 清屏重画）；关面板不杀终端，再开接回；结束显示「已结束」，可重新打开。*桌面和手机、亮暗在 headless Chromium 里验证：几何、溢出、ANSI 颜色、中文、四种入口和生命周期；像素级没看过，截图在 /tmp/calli-shots 留档*

## 20. 远程桌面

在网页里看、操作 agent 所在机器的 Linux 桌面（VNC）。和终端一样是给人的运维工具，不碰 agent 的会话，不替 agent 设 `DISPLAY`，也不起停 VNC 服务端。

- [x] daemon `desktop.ts`：在本机 5900–5909 找正在监听的端口（读 `/proc/net/tcp`，结果缓存 5 秒；不去连 VNC：TigerVNC 把没登录就断开的连接算作认证失败，五次后拒绝该地址的所有客户端），`CALLI_DESKTOP_VNC=host:port` 指定、`off` 关闭；`GET /api/desktop` 返回有没有、在哪个端口

- [x] 鉴权：浏览器 WebSocket 带不了 Authorization，先用 Bearer 换 60 秒票据（`GET /api/desktop/ticket?host=`，HMAC 绑定连接路径，带随机数，用一次作废）。票据总由 hub 签发、校验，被代理的机器信任自己的 socket
